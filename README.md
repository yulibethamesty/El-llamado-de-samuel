# El Llamado de Samuel

**El Llamado de Samuel** es una aplicación web creada para facilitar la
organización y gestión de retiros. Reúne en un solo lugar la información y las
tareas necesarias para coordinar a las personas, actividades y recursos del
retiro.

Su propósito es ayudar a los organizadores a mantener el trabajo ordenado y
accesible, apoyar la coordinación del equipo y simplificar la administración
general del evento. También incluye un control de activación para gestionar el
acceso autorizado a la aplicación.
